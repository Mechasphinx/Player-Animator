Player Animator
===============
Double-click "Player Animator.bat" to open it in its own window (uses Microsoft Edge, nothing to install).

Mouse in the view:   left-drag a limb = pose it (Drag tool)   left-drag empty space = orbit
                     right-drag = pan   wheel = zoom
Keys:  Space play   K add key   Delete remove key   Q swap weapon   D Drag tool   R Rotate   V Move
       1 Front   3 Side   7 Top   5 Perspective/Orthographic   Left/Right step a frame
       Ctrl+Z undo   Ctrl+Y redo   Ctrl+S save   Ctrl+C / Ctrl+V copy and paste keys
Timeline:  drag the ruler to scrub, drag keys to move them, double-click a row to add a key,
           drag empty space to box-select, Ctrl+wheel to zoom.
Import:  drop a .bbmodel, a Java .json with its .png, or a .geo.json with its .png onto the window.
